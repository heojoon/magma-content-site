## 재생성 및 권한 메모

- 제작 방식: OpenAI Codex 이미지 생성 도구의 `gpt-image-2-medium` 텍스트-투-이미지 결과를 사용해 신규 생성.
- 워크플로우: 원고 문단별 상황·핵심 아이템·조합 원리를 읽고 장면별 포토리얼 프롬프트를 설계 → 신규 이미지 생성 → Pillow로 1600×1000 RGB PNG 중심 크롭/리사이즈 → 직접 시각 검수.
- 외부 사진, 스톡 사진, 브랜드 로고, 상표 이미지, 워드마크, 워터마크는 사용하지 않음.
- 기존 웹 경로와 파일명을 유지해 원고/검토 HTML의 참조 호환성을 유지함.
- 범위 준수를 위해 기존 원고·최종 원고·검토 HTML·발행 스크립트·운영/개발 API는 수정하거나 호출하지 않고, PNG 6장과 이 README만 갱신함.

## 포토리얼 품질 점검 근거

- 6장 모두 새 포토리얼 생성본으로 교체했으며, 이전 SVG/HTML 렌더 일러스트나 드로잉 자산을 재사용하지 않음.
- 직접 시각 점검 결과:
  - 실제 사진형 렌즈감, 자연광/실내광, 얕은 피사계 심도, 피부·섬유 질감이 보임.
  - 손·얼굴·의복의 큰 비현실적 오류는 발견하지 못함.
  - 이미지 내부에 읽을 수 있는 텍스트, 로고, 워드마크, 워터마크, 간판 글자는 발견하지 못함.
  - 6장 모두 서로 다른 장소·구도·착장으로 구분됨.
- 장면별 배경 분리:
  - 썸네일: 하루의 다섯 장면을 한 오피스 에디토리얼 공간 안에서 암시.
  - 미팅: 넓은 회의실, 발표자, 테이블과 보드.
  - 집중 업무: 데스크, 노트북, 조용한 사무실.
  - 외부 이동: 여름 도심 보도와 이동 동선.
  - 워크숍: 냉방된 회의실, 긴 테이블과 보드.
  - 저녁 네트워킹: 어두운 식사/라운지 공간.

# 윤문 기록 | summer-resort-top5

## 결론
원고는 ‘휴양지 룩’이 아니라 출발부터 귀가까지 이어지는 정돈된 여행 옷장으로 정리했습니다. 다섯 코디는 제품 판매 제안이 아니라 장면별 조합 가설로 서술했습니다.

## 발행 전 확인 사항

1. 각 이미지 슬롯을 Mia가 제작한 실제 경로로 치환합니다.
2. 발행할 제품이 생기면 소재 혼용률, 케어라벨, 가격, 재고는 제품 상세 정보와 대조해 별도로 반영합니다.
3. 식당이나 목적지를 구체적으로 언급할 경우, 해당 업장의 공식 드레스코드와 현지 날씨를 확인합니다.
4. 외부 링크의 게시 상태와 원문 맥락은 발행 직전에 다시 확인합니다.

# 윤문 기록 | summer-office-look

## 결론
원고는 여름을 이겨 내는 옷이 아니라, 온도와 일정이 바뀌는 업무일에도 형태를 정돈하는 방법으로 썼습니다. 다섯 장면은 상품 판매 제안이 아닌 조합의 편집안이며, 실제 제품의 사양과 조직별 복장 기준은 확정하지 않았습니다.

## 점검 결과

| 점검 항목 | 결과 | 반영 내용 |

| 제목·슬러그 | 통과 | 슬러그 `summer-office-look`와 제목이 여름 업무일의 장면별 오피스룩이라는 주제로 일치합니다. |

| 이미지 슬롯 | 통과 | frontmatter에 썸네일 1개와 이미지 슬롯 5개를 넣었고, 본문 장면과 1:1로 연결했습니다. 실제 이미지 경로는 확정하지 않았습니다. |

| 과장·광고 톤 | 통과 | 느낌표와 "무조건", "완벽한", "필수", "압도적" 같은 단정 표현을 쓰지 않았습니다. |
| 맞춤법·중복 | 통과 | 장면명과 제품군을 대조해 같은 경계 문장이 반복되지 않도록 정리했습니다. |

## 발행 전 확인 사항

1. `{{THUMBNAIL_PATH}}`, `{{LOOK_01_PATH}}`부터 `{{LOOK_05_PATH}}`까지를 Mia가 확정한 실제 이미지 경로와 대체합니다.
2. CMS가 이미지 슬롯 문법을 다르게 요구하면, 원고의 alt 텍스트를 유지한 채 경로 표기만 변환합니다.
3. 실제 판매 제품을 언급하게 되면 소재 혼용률, 케어 라벨, 가격, 재고와 성능 문장을 제품 상세 정보로 다시 검토합니다.
4. 개별 기업·행사·업장 이름을 넣을 때에는 해당 공식 드레스코드와 최신 안내를 별도로 확인합니다.
5. 발행 직전에 외부 링크의 게시 상태와 인용 문맥을 다시 확인합니다.

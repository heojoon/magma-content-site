# 마스터 스토리보드 — 여행의 선

- 형식: 1920×1080, 16:9, 총 45초, 30fps
- 컨셉: A. 여행의 선
- 스타일: BlueKiwi MAGMA 다크 에디토리얼. 니어블랙 `#141414` 캔버스, 웜 오프화이트 `#F4F1EA`/`#EDEAE3` 타이포, 테라코타 `#C05621`은 여정선과 장면 인덱스에만 사용.
- 공통 안전영역: 좌우 120px, 상하 90px. 카피는 하단 360px 안에 고정하고, 피사체의 얼굴·상반신은 중앙 55% 영역에서 가리지 않는다.
- 전환: CSS 기반 다크 크로스페이드 + 테라코타 경로선 전진. 셰이더 전환은 사용하지 않는다.

## 제작 메모

- 이미지에 텍스트·로고가 없다는 기존 검수 기록을 유지한다. 영상 안에는 브랜드 워드마크나 로고를 추가하지 않는다.
- ‘편하다’, ‘구김이 없다’, 소재 기능성처럼 원문이 단정하지 않은 제품 성능 주장은 영상 문구로 넣지 않는다.
- 웹 히어로 루프는 별도 편집으로, 12초 동안 5개 이미지와 썸네일을 텍스트 없이 순환한다.
